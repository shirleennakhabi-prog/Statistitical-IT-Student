SUMMARY OF THE FIRST SIX TOPICS

1. Introduction to IT & Computers

This topic introduces the basic concepts of Information Technology (IT) and helps us understand the role computers play in handling information. IT mainly deals with the use of computers and communication systems to collect, process, store, and share data. We learn about the evolution of computers from early mechanical devices to modern digital systems.
It also explains the main characteristics of computers such as speed, accuracy, reliability, and the ability to store large amounts of data. Common computer applications are discussed, including use in business, education, health, banking, and scientific research.
The topic also introduces the main types of computers — such as supercomputers, mainframes, personal computers, laptops, and handheld devices — and how each type is suited for specific tasks.

2. Fundamentals of Computer Operations

The second topic focuses on how a computer works internally. Computers perform all tasks using the IPO cycle:

Input – receiving data from devices like keyboards, mice, or sensors.

Process – converting the input into useful information with the help of the CPU.

Output – displaying the result through monitors, printers, speakers, etc.

Storage – saving data temporarily (RAM) or permanently (hard disks, SSDs).


This topic also introduces the computer booting process, which includes powering on, loading the operating system, and making the system ready for use.
Other essential functions discussed include: 

The role of the CPU (Central Processing Unit) as the brain of the computer.

The concept of machine cycles (fetch, decode, execute).

How different components communicate through buses and ports.


Understanding this topic helps you grasp how computers complete tasks efficiently and why coordination between hardware and software is necessary.

3. Computer Hardware Basics

This section deals with all the physical components of a computer system.

Main Internal Components

Motherboard – main circuit board that connects all parts.

CPU – performs calculations and processing.

RAM (Random Access Memory) – temporary working memory used while programs run.

Storage devices – such as HDDs, SSDs, flash drives.


Input Devices

These allow the user to enter data into the computer. Examples: keyboard, mouse, scanners, barcode readers, microphones.

Output Devices

These present processed information to the user. Examples: monitors, projectors, printers, speakers.

Processing & Control Units

ALU (Arithmetic Logic Unit) handles mathematical and logical operations.

Control Unit manages instructions and directs overall operation.


The topic may also cover:

Difference between primary memory (RAM, ROM) and secondary memory.

Internal vs. external hardware components.

How hardware affects computer performance.

4. Computer Software Basics

Software refers to the programs and instructions that tell the hardware what to do. This topic explains the two major types of software:

1. System Software

This includes programs that manage and run the hardware:

Operating Systems (OS) like Windows, Linux, macOS — responsible for memory management, multitasking, file management, and device control.

Utility Programs such as antivirus, backup tools, disk cleaners.


2. Application Software

These are programs used by the user to perform real tasks:

Productivity software: Word processors, spreadsheets, presentation tools.

Statistical and analytical software: SPSS, R, Python, Excel.

Browsers: Chrome, Firefox.

Specialized apps: accounting systems, design tools, etc.


The topic also introduces concepts like open-source vs. proprietary software, installation and updating of programs, and how software interacts with hardware.


5. Data and Data Files

This topic explains what data is and how it is represented in computers. Data can be numerical, text, audio, images, or videos, and it must be converted into binary form (0s and 1s) for the computer to process it.

Types of Data:

Numeric

Textual

Multimedia

Logical (true/false)


The topic also explains how data is organized in files, and different file types such as:

Text files (.txt)

Document files (.docx, .pdf)

Image files (.jpg, .png)

Program files (.exe)


Other important terms include:

File naming conventions

File extensions

File directories and folders

Sequential vs. random file access


This topic is especially important in statistics because data must be correctly recorded, stored, and retrieved for analysis.

6. Disk Storage Fundamentals

This topic focuses on the devices used to store data permanently.

Types of Storage

1. Magnetic Storage – Hard Disk Drives (HDDs) use rotating disks.


2. Solid State Storage – SSDs use flash memory; faster and more reliable.


3. Optical Storage – CDs, DVDs.


4. Portable Storage – Flash drives, memory cards.



Key Concepts

How data is written on a disk (sectors, tracks, blocks).

File allocation methods – how the operating system organizes files.

Storage capacity – measured in bytes (KB, MB, GB, TB).

Access time – how quickly the device retrieves data.

Difference between volatile and non-volatile storage.
